# Dhruv Prajapati — Developer Portfolio

A responsive, animated personal portfolio for showcasing projects, skills, education, and contact details.

## Features

- Single-file website: all page styles, animations, language data, and project images are embedded in `index.html`.
- Responsive layout with animated sections and custom cursor effects.
- Dark theme and blue-tinted light theme.
- English, Gujarati, and Hindi language selector.
- Sections for About, Skills, Projects, Resume, Contact, and Settings.
- No PHP server or database required.
- Contact form opens the visitor's email application to send a message.

## Files

- `index.html` — the complete portfolio website.
- `README.md` — project information and publishing instructions.

## Publish with GitHub Pages

1. Upload `index.html` to the root of the GitHub repository's `main` branch.
2. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
3. After the Pages deployment completes, open the site link shown in the Pages settings.

The website is self-contained, so no asset folders need to be uploaded.
